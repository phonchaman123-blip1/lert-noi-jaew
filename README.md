# Lert Noi Jaew – Online Menu Web App

Live site: https://lert-noi-jaew.web.app

Website for my family's Isaan food shop at Phon Municipal Market, Khon Kaen.

## Features
- Menu showcase with photos and prices (current live version)
- Ordering version (`backup/index_order_version.html`):
  - Shopping cart and checkout flow in vanilla JavaScript
  - LINE LIFF login and sending order summaries to LINE chat
  - PromptPay QR generation (EMVCo TLV payload + CRC16 implemented from scratch)

## Tech
HTML, CSS, JavaScript, LINE LIFF, Firebase Hosting
